# odin-recipes

A recipe website project showcasing fundamental web development skills through a clean, user-friendly interface for sharing cooking recipes.

## What I Learned From This Project

### HTML Fundamentals
- **Semantic HTML Structure**: Building well-structured pages using proper heading hierarchy (h1, h2, h3) and semantic elements
- **Navigation**: Creating internal linking between pages using relative paths (`./recipes/lasagna.html`)
- **Lists**: Implementing both unordered (`<ul>`) and ordered (`<ol>`) lists for different content types
- **Images**: Embedding and describing images with proper alt text for accessibility
- **Meta Tags**: Setting up viewport and charset for responsive and properly encoded pages

### CSS Styling & Design
- **Custom Styling**: Creating a cohesive visual identity with custom fonts (Pacifico from Google Fonts) and color schemes
- **Layout Techniques**: Using containers, padding, and margins to structure content effectively
- **Responsive Design**: Implementing media queries to adapt the layout for mobile devices (removing colored margins on screens ≤768px)
- **Visual Effects**: Adding shadows, transitions, and hover effects to enhance user interaction
- **Background Colors**: Creating visual hierarchy through strategic use of background colors

### Best Practices
- **Code Organization**: Separating content (HTML) from presentation (CSS)
- **Documentation**: Including a LICENSE file to specify usage rights (MIT License)
- **Naming Conventions**: Using descriptive class names and file names for clarity
